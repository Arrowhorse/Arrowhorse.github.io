# Ayesha Kazi — Machine Learning & AI Portfolio

**Live Portfolio Website:** [https://arrowhorse.github.io](https://arrowhorse.github.io)

Source code for my personal engineering portfolio showcasing end-to-end Machine Learning, AI Engineering, and Data Science systems:

* **Chicago Crime Spatio-Temporal Hotspot & AI Explorer:** Automated Socrata REST API ingestion, cyclical temporal encoding, `MiniBatchKMeans` clustering, 30-day rolling Z-score anomaly detection, and a 3D `PyDeck` + `Streamlit` dashboard with weekly GitHub Actions CI/CD retraining.
* **B2B Regional Tire Distribution & Fleet Optimizer:** Multi-stop highway delivery route optimizer using A* search with a memoized Prim's Minimum Spanning Tree (MST) heuristic over real OSRM road-network matrices, truck payload validation, and fleet cost modeling.
* **Autonomous Warehouse AMR Route Optimizer:** Multi-SKU order-picking path planner benchmarking optimal A* (Prim's MST heuristic) against a greedy nearest-item BFS baseline across warehouse shelving topologies.
